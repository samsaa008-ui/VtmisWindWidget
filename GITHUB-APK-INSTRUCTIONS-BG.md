# Как да получиш готов APK чрез GitHub

Проектът вече съдържа автоматична GitHub Actions компилация.

## 1. Създай хранилище

1. Влез в GitHub.
2. Натисни **New repository**.
3. Име: `VtmisWindWidget`.
4. Избери **Private** или **Public**.
5. Не добавяй README, .gitignore или лиценз.
6. Натисни **Create repository**.

## 2. Качи файловете

1. В новото хранилище натисни **uploading an existing file** или **Add file → Upload files**.
2. Разархивирай ZIP файла на компютър.
3. Качи цялото съдържание на папката, включително скритата папка `.github`.
4. Натисни **Commit changes**.

Важно: `.github/workflows/build-apk.yml` трябва да се вижда в GitHub. Ако качваш през телефон и скритата папка не се показва, използвай приложението за файлове с включено „Показване на скрити файлове“ или качи през компютър.

## 3. Стартирай компилацията

1. Отвори раздел **Actions**.
2. Избери **Build Android APK**.
3. Натисни **Run workflow**.
4. Изчакай зелената отметка.

При първото качване компилацията обикновено се стартира и автоматично.

## 4. Свали APK

1. Отвори завършеното изпълнение в **Actions**.
2. В долната част, под **Artifacts**, натисни `VtmisWindWidget-APK`.
3. Ще се свали ZIP архив.
4. Разархивирай го.
5. Вътре е `app-debug.apk`.

## 5. Инсталирай на телефона

1. Изпрати `app-debug.apk` до телефона чрез Google Drive, Gmail, Viber или друг канал.
2. Отвори файла.
3. Разреши „Инсталиране на неизвестни приложения“ за приложението, от което отваряш APK.
4. Натисни **Инсталирай**.
5. Задръж върху началния екран → **Widgets** → **Вятър Варна**.

## Забележка

APK е debug версия, подписана автоматично с временния debug сертификат на GitHub runner. Тя е подходяща за лично инсталиране и тестване. За публикуване в Google Play е нужен release подпис и отделна конфигурация.
